Screens (desktop)

Same identity, patterns, and screen inventory as mobile, in a sidebar-plus-content window (Tauri v2, native title bar). Connectors is promoted to a top-level sidebar item; the trust strip is pinned to the sidebar bottom so the active trust tier is visible on every screen, not just Chat. The connector inventory is platform-specific by design — mobile's Device section (Brightness, Torch) is phone hardware and has no desktop counterpart; desktop's Tier 3 set is its own (research 0011).
